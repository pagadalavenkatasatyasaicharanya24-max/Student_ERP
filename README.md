# Student ERP

## Project Overview

Student ERP is a web-based student management module developed as part of a Cloud-Based ERP Platform for college management.

## Purpose

The system is designed to provide students with a centralized platform to access and manage their academic information.

## Student Module

The Student Module will include:

- Student Login
- Student Dashboard
- Student Profile
- Subjects and Courses
- Assigned Faculty
- Attendance
- Marks and Results
- Timetable
- Fee Details
- Notifications

## Technologies

- HTML
- CSS
- JavaScript
- Python Flask
- MySQL

## Development Plan

The application is being developed and tested locally first. Cloud deployment will be implemented in a later phase.

## Project Status

Currently under development.
